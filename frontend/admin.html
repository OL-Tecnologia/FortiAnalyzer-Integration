      Pattern devices

      O que é? Uma expressão regular (regex) criada neste sistema — não existe no FortiGate/FortiAnalyzer.

      Para que serve? Ler o hostname dos dispositivos no FAZ e montar a hierarquia do PDF (região → site → device).

      O que faz? Só entram no relatório unificado os devices cujo nome casar com o pattern.

      Como preencher:

      1. No FortiAnalyzer do cliente que está cadastrando, anote 1–2 hostnames reais dos FortiGates (ex.: fw-norte-matriz).
      2. Identifique no nome a região e o site (partes que mudam entre devices).
      3. Monte a regex com grupos obrigatórios (?P<region>...) e (?P<site>...). Opcional: (?P<prefix>hafw\d+) para HA.
      4. Partes fixas do nome do cliente escreva como literais; partes variáveis use [a-z]+, [a-z0-9]+ ou .+.
      5. Teste mentalmente: o hostname deve casar inteiro (a regex começa com ^ e termina com $).
      6. Cada tenant tem o próprio pattern. Não reutilize naming de outro cliente. Se deixar vazio, o sistema aplica um padrão genérico — ajuste sempre ao naming deste FAZ.

      Exemplo ilustrativo (hostname fictício fw-norte-matriz):

      ^(?:(?P<prefix>hafw\d+)|fw)-(?P<region>[a-z0-9]+)-(?P<site>.+)$

      → região = norte, site = matriz

      Exemplo com trecho fixo do cliente (fw-sul-empresa-filial01):

      ^(?:(?P<prefix>hafw\d+)|fw)-(?P<region>[a-z]+)-empresa-(?P<site>.+)$

      → região = sul, site = filial01 (troque empresa pelo literal real deste cliente)
