FortiAnalyzer Reports - Cruz Azul
==================================

VERSÃO COMPILADA (.exe) — RECOMENDADO PARA O TIME
-------------------------------------------------

  Pasta: dist\FortiAnalyzer-Reports\

  Duplo clique em:

      FortiAnalyzer-Reports.exe

  O portal abre em http://localhost:8000/login.html
  Não precisa de Python nem instalação.

  Na primeira execução, o .env é criado automaticamente (config Cruz Azul).
  Credenciais FAZ: informe no login do portal.

  Distribua a pasta FortiAnalyzer-Reports\ inteira (não copie só o .exe).


DESENVOLVIMENTO / INSTALAÇÃO POR CÓDIGO-FONTE
---------------------------------------------

  1. Duplo clique em install.bat (assistente em http://127.0.0.1:8765)
  2. Ou: py -3 -m venv .venv && pip install -e .
  3. Uso diário: FortiAnalyzer Reports.bat


COMPILAR O .EXE (EQUIPE DE DESENVOLVIMENTO)
-------------------------------------------

  powershell -ExecutionPolicy Bypass -File install\build_app.ps1

  Gera dist\FortiAnalyzer-Reports\ para distribuir ao time.


TERMINOLOGIA (relatórios)
-------------------------

  Unidade regional  — ex.: CAS - Campinas, SPO
  Unidade (site)    — ex.: Ambulatório, Colégio
  Dispositivo       — hostname FortiGate no FAZ (fw-{região}-cruz-azul-{site})


REQUISITO (somente versão por código-fonte)
-------------------------------------------
  Python 3.11+ com "Add to PATH"
  https://www.python.org/downloads/
